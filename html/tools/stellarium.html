Enable Offline HiPS Surveys in Stellarium

The standard survey in Stellarium is as boring and uninformative as possible. Here I will show you how to make it much better.

Download survey using this script:
HIPS-survey-downloader

Configure Stellarium:
Add these lines to the config.ini file (%appdata%/Stellarium):

[hips] show = true sources/1/url = file:///E:/survey/NSNS_DR_01_tc8/hipslist sources/2/url = http://alasky.u-strasbg.fr/MocServer/query?*/P/*&get=record sources/3/url = https://data.stellarium.org/surveys/hipslist sources/size = 3 surveys/1/url = file:///E:/survey/NSNS_DR_01_tc8 surveys/size = 1

Add configuration files:
Add these two files to the root directory of your HiPS survey. (if the survey is different, you need to change the contents of the files, plus change the path to the root folder of the survey):

hipslist file:
creator_did = ivo://simg.de/P/NSNS/DR0_1/tc8 obs_title = NSNS Offline Survey hips_release_date = 2025-06-07T16:33Z hips_service_url = file:///E:/survey/NSNS_DR_01_tc8 hips_status = public hips_order = 5 hips_tile_format = png dataproduct_type = image moc_sky_fraction = 1

Directory structure:
Your survey directory should look like this:
E:\SURVEY\NSNS_DR_01_TC8 +---hipslist +---properties +---Norder0 | \---Dir0 +---Norder1 | \---Dir0 +---Norder2 | \---Dir0 +---Norder3 | \---Dir0 +---Norder4 | \---Dir0 \---Norder5 +---Dir0 \---Dir10000

Final result:
After that, go to Stellarium -> F4 -> Surveys and find the offline survey!
